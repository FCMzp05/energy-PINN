# energy-PINN

Code for Peng Zhang, Xianqiao Wang, and Keke Tang, [An energy-based differentiable finite element framework for elastic and path-dependent elastoplastic solids](https://doi.org/10.1016/j.finel.2026.104647), *Finite Elements in Analysis and Design* 262, 104647 (2026).

Each benchmark is a single-file script: `*_feinn*.py` is the energy-based differentiable finite element solver (Python) and `*_fem*.jl` is the corresponding finite element reference (Julia).
